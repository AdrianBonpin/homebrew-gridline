# Homebrew Tap for Gridline

[Gridline](https://github.com/AdrianBonpin/gridline) is an open-source,
cross-platform database GUI client (PostgreSQL, MySQL/MariaDB, SQLite).

## Install

```sh
brew tap AdrianBonpin/gridline
brew install --cask gridline
```

Or in a single command:

```sh
brew install --cask AdrianBonpin/gridline/gridline
```

Upgrade later with `brew upgrade --cask gridline`.

## About this repo

`Casks/gridline.rb` is **generated and pushed automatically** by the release
workflow in [`AdrianBonpin/gridline`](https://github.com/AdrianBonpin/gridline)
after each GitHub release is published. Do not edit it by hand — any manual
change will be overwritten on the next release.
